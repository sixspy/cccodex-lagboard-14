# 停用排除说明（封板钉死）

封板时间：2026-11-19。本册已钉死，排除当天不许改口；后续只准按册执行，不准修订口径。

## 正确性口径（甲路径，唯一）

停用排除只走**甲路径**：停用标记与水位聚合字段同库一次提交排除该源，且历史到达只读保留。

- 一次提交：`POST /api/sources/{source}/deactivate` 在同一事务内写入
  `deactivated=1`、`deactivated_at`、`output_mode='停用排除'`，并落一条「停用排除」留痕，同库一次提交。
- 乙路径（排除影子表）**不启用**；甲乙不得混用。任何携带 `path=乙` 的排除请求即偏离，拒绝并记「排除偏了」。
- 历史到达只读保留：排除不删、不改 `arrivals` 历史行；物理删史即偏离，`DELETE /api/arrivals/{id}` 一律拒绝并记「排除偏了」。

## 写路径不变量

1. 停用源不再抬水位：`POST /api/arrivals` 命中停用源返回 409「源已停用排除，水位不再刷新」，不插到达、不刷水位。
2. 停用源不再补齐：`POST /api/catchup/{source}` 命中停用源返回 409，对账账册不再登记。
3. 重复停用返回 409「已停用排除」，不重复记「停用排除」留痕。
4. 停用操作与水位刷新（到达登记、补齐恢复）抢写时排队占锁（`EXCLUSION_LOCK`）；后到者只记「停用排除争用」留痕后排队，不报错、不丢史。
5. 偏离本册一律拒绝并记「排除偏了」。

## 五处排除（验收对齐）

策略附页（时限台分级表）、源目录（左侧源列）、水位卡片（汇总卡）、对账账册（补齐记录）、到达列表（到达时间线）
五处默认一律排除停用源，数据同源对齐；史迹经 `?scope=all` 只读可查，停用源史迹带标记展示。

## 入口与边界

- 停用操作挂在时限台（滞后分级）源行菜单「停用排除」按钮，不另起排除工作台。
- 登录沿用本仓会话（`POST /api/login` 签发 Bearer 令牌）；库文件沿用本仓卷 `data/app.db`。
- 留痕查询：`GET /api/exclusion/events`；本册查询：`GET /api/exclusion/manual`（只读，无改口接口）。
